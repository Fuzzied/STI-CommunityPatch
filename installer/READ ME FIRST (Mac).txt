Space Travel Idle Community Patch 0.1.2, Mac
============================================

Thanks for trying this. It is free of course.

New in 0.1.2: The mod's settings lists fit your screen and scroll when they
have to, and Esc closes the Welcome Back popup.

There is no Python. One script puts it in, everything is on, and one
settings file turns things off.

Nothing here has been tested on a real Mac yet. It is written against what
the Mac build of the game should look like. If you try it, please tell me
how it went, good or bad. Nothing you do here can hurt your save, which
lives in your home folder, not in the game folder.


Before you start: use the normal Steam branch
---------------------------------------------

In Steam: right-click Space Travel Idle, Properties, Betas. Beta Participation
should say None.

On beta or beta-danger Steam gives a Mac a much older game (0.2.2, not 0.3.5).
Neither the community version nor this patch fits it.


You need the community version first
------------------------------------

This patch is made for Space Travel Idle v0.35.43, the community version.
Izm_ shares it on the Space Travel Idle Discord, and it is here too:

    https://drive.google.com/file/d/12rzd9zlH0ixN5Saq7-1-CaeDvJwAeP3I/view?usp=sharing

It is packed for Windows. On a Mac its files go inside the app instead:
right-click Space Travel Idle.app, Show Package Contents, then
Contents/Resources/Data. That has not been tried on a real Mac yet either,
so shout if it looks different.


Installing
----------

Close the game first.

Double-click "Install Community Patch.command".

macOS will probably refuse the first time and say it is from an unidentified
developer. That is normal for any script that arrives in a zip. Right-click
the file instead, choose Open, and click Open in the box that appears. You
only have to do that once.

It finds the game by itself. If it cannot, it asks, and you drag the game
folder (the one holding Space Travel Idle.app) into the window.

Coming from 0.1? The script also takes out the game data 0.1 wrote, so you
do not have to do anything extra.


The one step the script cannot do for you
-----------------------------------------

On a Mac the game has to be started through a small script, and only Steam
can be told to do that. The install script prints the exact line when it
finishes, and copies it for you. It looks like this:

    "/Users/you/Library/Application Support/Steam/steamapps/common/Space Travel Idle/run_bepinex.sh" %command%

In Steam: right-click Space Travel Idle, Properties, General, and paste it
into Launch Options. Then start the game from Steam as normal.


Did it work?
------------

In the game: Settings gets a Community mod section at the bottom of the
right hand column.

In the game folder: BepInEx/LogOutput.log. Its first lines say which
version of the patch is running and list every plugin that loaded.

If the game starts but LogOutput.log never appears, the loader is not
getting in. Send me these, and I can usually tell what happened:

    space-travel-idle-install-report.txt, which the script put on your Desktop
    The game folder/BepInEx/LogOutput.log, if there is one
    ~/Library/Logs/Ayatsuji/SpaceTravelIdle/Player.log

To get to that last one: in Finder press Cmd+Shift+G, paste the path, and
press Enter.


Turning things off
------------------

Everything is on. After the game has started once, there is a settings file
in the game folder:

    BepInEx/config/STI Community Patch.cfg

Open it in TextEdit. Every part of the patch has a line there, with a short
description above it. Change true to false on the ones you do not want,
save, and restart the game.

Some names in there are vague on purpose, so the file does not tell you
about a planet, a card or an upgrade you have not found yet.

The in game Settings panel gets these switches in 0.2.


The Balancer
------------

I tuned this patch with a second mod on, the Unlocker by Berserker. I call it
the Balancer. Without it and my settings, I lost every high level fight,
trips took twice as long and Big Bang paid nothing unless I beat my best
score.

It comes with the patch, with the settings I used, so it is on too. If you
already had your own settings for it, the script keeps them as
STIU.cfg.before-community-patch.

Rather play the plain game? In the game folder, delete BepInEx/plugins/STIU
and BepInEx/config/STIU.cfg. Version 0.2 will be balanced for that too.

Not my work. It is shared under its MIT licence, which sits next to it.
Source: https://github.com/Berserker66/STIU


Taking it all off
-----------------

Clear the Launch Options line in Steam. That alone starts the game without
any of it. To tidy up, also move the BepInEx folder, run_bepinex.sh and
libdoorstop.dylib from the game folder to the Trash.

Worth knowing: Steam verifying the game puts back Steam's own game files,
and that takes out the community version too. Put it back in afterwards.


Repairing a scrambled priority list
-----------------------------------

There was a bug in an earlier version of Auto Start where a research or
building rebuilt on load could end up at the bottom of the priority list.
The cause is fixed, but a list that already got scrambled stays scrambled.

There is a repair tool in STI Community Patch/tools/repair_priority_order.py.
It needs Python, so tell me on Discord first and I will walk you through it.
