Space Travel Idle Community Patch 0.1.2, Windows
================================================

Thanks for trying this. It is free of course.

New in 0.1.2: The mod's settings lists fit your screen and scroll when they
have to, and Esc closes the Welcome Back popup.

There is no Python and no setup. You unzip it into the game folder and
start the game. Everything is on, and one settings file turns things off.

Your save is not in the game folder. It lives in your own AppData folder and
nothing in here touches it.


You need the community version first
------------------------------------

This patch is made for Space Travel Idle v0.35.43, the community version.
Izm_ shares it on the Space Travel Idle Discord, and it is here too:

    https://drive.google.com/file/d/12rzd9zlH0ixN5Saq7-1-CaeDvJwAeP3I/view?usp=sharing

Put that in first, the way its own readme says. Then come back here.


Coming from 0.1?
----------------

0.1 wrote its changes into the game's own data file. Since 0.1.1 the patch makes
them while the game runs instead, and it will not do that on top of 0.1's. So after
you have unzipped this one (below), double-click "Undo 0.1 game data.bat" in
the game folder once, with the game closed. That is all. Your 0.1 settings
and saves stay as they are.

If you forget, the game tells you in a box at the top of the screen.


Installing
----------

Close the game first. And never end it from Task Manager, the game writes
your save on the way out.

1. Find the game folder. In Steam: right-click Space Travel Idle, Manage,
   Browse local files. It is the folder with SpaceTravelIdle.exe in it.

2. Open the zip, press Ctrl+A to select everything in it, and drag it all
   into the game folder. If Windows asks about replacing files, say yes.

   Careful with "Extract All": Windows adds the zip's name as one more
   folder at the end of the path. Delete that last part, so it unzips
   straight into the game folder.

3. Start the game from Steam as normal.

When you are done, the game folder has winhttp.dll and a BepInEx folder
next to SpaceTravelIdle.exe. If they ended up one folder deeper, move them
up.


Did it work?
------------

In the game: Settings gets a "Community mod" section at the bottom of the
right hand column, and an "Auto start" section under Tutorial Progress.

In the game folder: BepInEx\LogOutput.log. Its first lines say which
version of the patch is running and list every plugin that loaded.

If neither is there, send me these two files and I can usually tell what
happened without guessing:

    The game folder\BepInEx\LogOutput.log
    C:\Users\<you>\AppData\LocalLow\Ayatsuji\SpaceTravelIdle\Player.log

To get to that second one quickly: press Windows+R, paste
%userprofile%\AppData\LocalLow\Ayatsuji\SpaceTravelIdle and press Enter.


Turning things off
------------------

Everything is on. After the game has started once, there is a settings file
in the game folder:

    BepInEx\config\STI Community Patch.cfg

Open it in Notepad. Every part of the patch has a line there, with a short
description above it. Change true to false on the ones you do not want,
save, and restart the game. Change it back to turn it on again.

Some names in there are vague on purpose, so the file does not tell you
about a planet, a card or an upgrade you have not found yet.

The in game Settings panel gets these switches in 0.2.


The Balancer
------------

I tuned this patch with a second mod on, the Unlocker by Berserker. I call it
the Balancer. Without it and my settings, I lost every high level fight,
trips took twice as long and Big Bang paid nothing unless I beat my best
score.

It comes in the zip, with the settings I used, so it is on too.

Rather play the plain game? Delete the folder BepInEx\plugins\STIU and the
file BepInEx\config\STIU.cfg. Version 0.2 will be balanced for that too.

Already use the Unlocker with your own settings? The zip brings mine in
BepInEx\config\STIU.cfg. Copy yours somewhere safe before you unzip, and
put it back after if you want yours.

Not my work. It is shared under its MIT licence, which sits next to it.
Source: https://github.com/Berserker66/STIU


Taking it all off
-----------------

Delete winhttp.dll from the game folder and the game starts without any of
it. To tidy up completely, also delete the BepInEx folder, the "STI
Community Patch" folder, doorstop_config.ini, .doorstop_version,
changelog.txt and the two files this readme came with.

Worth knowing: Steam verifying the game puts back Steam's own game files,
and that takes out the community version too. The patch itself stays, but
it is made for the community version, so put that back in afterwards.


Repairing a scrambled priority list
-----------------------------------

There was a bug in an earlier version of Auto Start where a research or
building rebuilt on load could end up at the bottom of the priority list,
under your Accumulation Layers, and the mod would then remember it there.
The cause is fixed. A list that already got scrambled stays scrambled,
because the wrong order is what got written down.

If that happened to you, there is a repair tool in
STI Community Patch\tools\repair_priority_order.py. It needs Python, so
tell me on Discord first and I will walk you through it. It asks for the
planet as a number, and guessing at that number is the one way to make
things worse rather than better.
